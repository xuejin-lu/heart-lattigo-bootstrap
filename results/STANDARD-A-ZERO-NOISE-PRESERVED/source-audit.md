## Bootstrap compressed-key usage evidence

At base `5dbffbdea05394de2ca3a432ed5318aa832e3f40`, `circuits/ckks/bootstrapping/keys.go` calls `GenEvaluationKeyNew`, `GenRelinearizationKeyNew`, and `GenGaloisKeysNew` without compressed parameters. The only `Compressed: true` occurrences found in `core/rlwe` were focused unit/serializer tests. Even though the current Bootstrap constructor uses uncompressed keys, the generic `EvaluationKey.Expand` path is in this experiment's correctness test scope and must remain `a=0`.

## Audit conclusion

All single-party Bootstrap `a` generation paths converge on the Q or QP sampler in `encryptZeroSk`; compressed-key reconstruction is the second source that must be neutralized. Public-key encryption's `u`, `e0`, and `e1` are separate samplers and must remain unchanged; ciphertext `c1` must not be cleared. Multiparty CRS paths are explicitly excluded by the user's scope decision.

## Post-implementation verification notes

- The implementation leaves both `uniformSampler.Read` calls intact in `encryptZeroSk` and the seed-driven `uniformRingQPSampler.Read` intact in `EvaluationKey.Expand`; it zeroes only the sampled buffer after each draw.
- The deterministic tests replay the corresponding uniform draw before the error draw, compare secret-key and public-key error values against the deterministic sampler stream, count both public-encryption error draws, and capture/compare the sampled `e0` and `e1` for fixed seeds.
- In QP public-key encryption, the existing `ModDownQPtoQ` can reduce the small sampled errors to a zero ciphertext component after `a=0`. The test therefore verifies both nonzero error samples before modulus-down and deterministic output, while asserting nonzero output `c1=e1` in the Q-only path. No ciphertext component is cleared by the implementation.
- Added verification covers uncompressed general/relinearization/Galois keys, dimension-switch keys in both directions, standard/conjugate-invariant ring-swap keys, compressed expansion, and a generated E=32 Bootstrap key set at a small test ring degree. These tests inspect Q and P residues and do not execute Bootstrap.
