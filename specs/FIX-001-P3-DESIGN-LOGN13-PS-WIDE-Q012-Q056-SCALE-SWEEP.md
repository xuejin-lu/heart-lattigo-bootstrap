## Why this task supersedes the local G0 closure

The previous source-faithful diagnostic established:

- D q0=56 / planScale2^92 full-system control passes at public-like `0.005554220603853743`.

- compare against independent mathematical/oracle semantics and full-system outputs.

# Mathematical model

Let

`Q012 = q0*q1*q2`.

Throughout PS, Q012 is the authoritative signed CRT domain. At every centered-sensitive operation the intended integer must satisfy:

`|x| < Q012/2`.

The logical CKKS Level still decreases according to the original PS schedule. A Rescale at level L divides by the **actual logical divisor `Q[L]`**, even though only q0/q1/q2 are authoritative. Implement diagnostic Rescale by exact centered reconstruction from Q012, signed nearest division by `Q[L]`, then re-encode the quotient into q0/q1/q2. q2 is an authority limb, not necessarily the divisor limb.

No q3+ limb may be used as an arithmetic source.

# Fixed architecture for this experiment

## Parameters

- LogN13 only.
- diagnostic q0 = 56 bits.
- retain the current q1 and q2 generated by the same parameter builder; report their exact bit lengths and values.

## Q012 authority interval

Q012 must remain authoritative for the complete PS phase:

1. exact PS input lift Q01→Q012;
2. all required generated powers, including T2/T3/T4/T6/T8/T16;
3. all baby-step coefficient operations;
4. all giant-step Rescale / multiply / aligned add operations;
5. actual Fast zero-secret relinearization points;
6. final PS relinearization;
7. final PS Rescale;
8. only then prove Q01 uniqueness and contract once to Q01.

No intermediate Q012→Q01 contraction is allowed.

# Required evaluator semantics

Use the same common PS planner/decomposition as production Fast.

The Q012 reference evaluator must mirror mathematical Fast semantics, but it does **not** need intermediate row identity with the old q01 evaluator.

## Add/Sub

Operate component-wise modulo q0/q1/q2, preserve degree/metadata according to Fast semantics.

## Mul

For degree1×degree1 produce degree2:

- c0 = a0*b0
- c1 = a0*b1 + a1*b0
- c2 = a1*b1

under q0/q1/q2.

Under zero-secret semantics, retain c2 until the same logical relinearization point as the PS schedule.

## Relinearize

Use the established Fast zero-secret semantic exactly. Do not introduce Standard evaluation-key arithmetic.

## Scalar / coefficient operations

Encode coefficients at the planner-assigned scale using the same coefficient semantics. Carry q0/q1/q2 consistently.

## Scale alignment

Follow the planner/evaluator's exact integer-ratio scale alignment policy. Record the integer multiplier and metadata target. Do not require equality with an old q01 rounded branch.

## Rescale

Diagnostic exact implementation:

1. reconstruct centered signed coefficient from q0/q1/q2;
2. divide by actual logical `Q[level]` with the exact accepted signed nearest-rounding rule;
3. reduce quotient into q0/q1/q2;
4. lower logical Level exactly once;
5. update Scale exactly by division by `Q[level]`.

Big.Int is allowed for this design proof only. Mark it explicitly non-production.
